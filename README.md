# faran-io.github.io

The root of Faran, LLC's GitHub Pages domain. It exists for `app-ads.txt`, which AdMob reads at the root of the
website listed on each app's store page, and it sends visitors on to the apps site
([faran-io/faran-apps](https://github.com/faran-io/faran-apps), served at https://faran-io.github.io/faran-apps/).
